# AUTH SERVICE


---

## MAIN FEATURES

- JWT-based authentication with BCrypt password hashing
- Register/login/logout enpoints
- PostgreSQL database
- Docker Compose containerized
- Prometheus/Grafana setup

---

## QUICKSTART

```bash
git clone https://github.com/COJIDAPNOSTb/note-project.git
cd note-project
docker-compose up --build
```

Once started, the server runs on:
**http://localhost:8081**

---

## OTHER ENDPOINTS

**http://localhost:3001** - Grafana Metrics
**http://localhost:9091** - Prometheus Metrics
